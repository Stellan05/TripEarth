# Travel Atlas 开发计划

> **适用场景：** Vibe Coding — 个人独立开发，快速迭代，先跑起来再优化。
> **核心原则：** MVP 只做"能用"级别，不做过早优化。

---

## 1. 产品定位

**一句话：** 一个以 3D 地球为交互核心的个人旅行记录与回忆工具。

**目标用户：** 热爱旅行的个人用户（前期就是你一个人用）。

**核心体验：** 打开网站 → 看到一颗漂亮的 3D 地球 → 去过的国家闪闪发光 → 点击进去全是回忆。

**竞品区分：** 不是地图标注工具（没那么多 POI），不是旅行攻略（不做推荐），而是**个人旅行记忆的可视化**。

---

## 2. MVP 功能（v0.1 — 2~3 周）

### 2.1 国家级别的地球交互

- 3D 地球可旋转/缩放
- 去过 = 高亮（金色/暖色），想去 = 标记（星标），未去 = 灰色
- 点击国家弹出信息卡片（去过多少次，最近一次时间）
- 国家数据存在后端，前端只做渲染

### 2.2 国家详情页

- 国家信息：名称、国旗、去过次数、旅行时间列表
- 城市标记（不画城市级地图，只在地图上标大致位置点）
- 旅行路线（线路连接城市，按行程分段）
- 该国家的照片墙（网格展示，点击放大）

### 2.3 基础数据录入

- 手动录入一次旅行（国家、城市列表、日期范围、照片上传）
- 路线编辑：添加城市、连接顺序、选择交通方式
- 航班信息：航班号、航空公司、机型、起降时间

### 2.4 收藏功能

- 标记"想去的国家"和"想去的城市"
- 地球上有视觉区分

### 2.5 个人旅行手记

- 每个国家/每次旅行可写 Markdown 手记
- 支持配图

**MVP 不做的：** 飞行轨迹回放动效、时间轴、旅行统计、社交功能。

## 5. 技术建议

### 5.1 3D 地球

**推荐：CesiumJS**

- 更优秀的三维地球渲染（原生椭球体、真实大气散射）
- 真实光照（太阳位置、昼夜分界）
- 丰富的 Camera 控制（FlyTo 平滑过渡、惯性旋转、自然缩放）
- 支持 Cesium World Terrain（地貌细节：山脉、森林、沙漠、海洋）
- 后续可扩展性更高（3D 城市、航班轨迹动画、时间变化）
- 替代方案：Globe.GL + Three.js（更轻量但缺乏 terrain 和大气效果）

### 5.2 国家详情中的地图

**推荐：Leaflet.js + OpenStreetMap 瓦片**

- 轻量免费，不需要 Mapbox Token
- 城市标点 + 路线连线是它的强项
- 配合 `leaflet-polyline` 做路线分段颜色

### 5.3 后端

**按 CLAUDE.md 技术栈：Spring Boot 3 + MyBatis-Plus + MySQL + Redis**

MVP 阶段表结构概要：

```
countries (code, name, flag_emoji, continent)
trips (id, title, country_code, start_date, end_date, notes_md)
trip_cities (id, trip_id, city_name, lat, lng, sort_order)
trip_routes (id, trip_id, from_city_id, to_city_id, transport_type, sort_order)
flights (id, route_id, flight_no, airline, aircraft, departure_time, arrival_time)
photos (id, trip_id, url, caption, taken_at)
wishlist (id, type, country_code, city_name, note)
```

### 5.4 前端

**Vue 3 + TypeScript + Vite + Element Plus**（匹配技术栈）

- 地球组件封装为独立 Vue 组件，通过 props 传入访问数据
- 地图组件封装为独立组件，支持标点和路线
- 照片上传直接用 Element Plus Upload + 后端本地存储（先不做 OSS）

### 5.5 MVP 阶段的简化策略

- **不做用户系统：** 单用户模式，硬编码 user_id = 1，登录后面再加
- **不做 OSS：** 照片直接存服务器本地磁盘
- **不做动画：** 飞行轨迹回放放 v0.2，MVP 只展示静态弧线
- **不做响应式：** MVP 只适配桌面端（1920×1080 / 1440×900）

## 6. 开发顺序

```
第 1 周：项目骨架 + 地球
  Day 1-2: 前后端项目初始化，数据库建表，基础 CRUD（国家、旅行）
  Day 3-4: CesiumJS 集成，3D 地球渲染，Terrain 地貌 + 国家颜色 overlay
  Day 5: 地球点击交互，弹出国家信息卡片

第 2 周：数据录入 + 国家详情
  Day 1-2: 新增/编辑旅行页面（表单 + 照片上传）
  Day 3-4: 国家详情页（Leaflet 地图 + 城市标记 + 路线连线）
  Day 5: 照片墙展示

第 3 周：收藏 + 手记 + 收尾
  Day 1-2: 想去清单（收藏功能 + 地球星星标记）
  Day 3-4: 旅行手记（Markdown 编辑 + 展示）
  Day 5: Bug 修复、样式打磨、演示准备

v0.2 起：
  飞行轨迹回放 → 旅行统计 → 时间轴 → 社交功能
```

## 补充说明

1. **照片存储：** MVP 阶段直接存服务器 `uploads/` 目录，通过 Spring Boot 静态资源映射访问。v0.2 再考虑 OSS/CDN。
2. **GeoJSON 数据：** 国家边界 GeoJSON 可从 Natural Earth 下载（110m 精度足够），大小约 1-2MB，放前端 public 目录。用于 Cesium GeoJsonDataSource 渲染国家 overlay。
3. **城市坐标：** 先用简单的 JSON 列表维护（从 SimpleMaps 或 GeoNames 获取一批基础数据），不要为 MVP 接地理编码 API。
4. **飞行轨迹弧线：** 后期用 Three.js 的大圆弧插值（Great Circle），两个经纬度之间插 N 个点形成弧形，比直线好看得多。
5. **无 API Key 依赖：** MVP 阶段所有 2D 地图瓦片用免费 CartoDB，3D 地球使用 Cesium Ion 默认 Token（CesiumJS 内置），不依赖任何付费外部服务。
